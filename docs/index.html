07

満車だったら？ ─ プランB と FAQ

🔄① akippaのキャンセル待ち

公式駐車場は前日まで無料キャンセル可のため、直前に空きが出ることがあります。公式駐車券ページをリロード。

🚉② 近隣駅パーク&ライド

籠原・行田など高崎線の隣接駅前のコインパーキングに停めて1〜2駅だけ電車移動する方法。渋滞と出庫待ちを丸ごと回避できます（※一般的なテクニックで大会公式の案内ではありません）。

🕘③ 時間をずらす

19時開放の八木橋・イオン熊谷を使って後半戦だけ観覧、または22時過ぎの規制解除後までゆっくり待つ。

予約なしで公式駐車場に行ったら停められる？

停められません。公式有料駐車場は akippa での完全事前予約制です（本日昼時点で第1は残りわずか・第2は完売）。バイクのみ1台1,000円(現金)で直接来場できます。

何時までに着けば停められる？

公式駐車場(予約済)は13:00開場・20:00入場締切です。市街地の無料開放は地方庁舎(8:30〜)以外は夕方以降の開放で、コインパーキングは例年夕方前に満車が目立ちます。車で行くなら15時前の到着を目安に、余裕を持って動くのがおすすめです。

雨が降りそう。開催されるかどうかはどこで確認？

当日10時から自動音声案内（050-3665-9671）で確認できます。荒天の場合は8/9(日)に順延、9日も開催できない場合は中止です。熊谷観光局サイトと合わせて確認してください。順延時は駐車券の予約は自動で有効になります。

体の不自由な家族がいます。近くに停められる？

第1公式有料駐車場のA区画に「思いやり駐車場」があります。障害者手帳等の提示で利用でき予約は不要ですが、台数限定のため満車時は利用できません。早めの到着が安心です。

自転車・バイクで行く場合は？

自転車：会場周辺への乗り入れは控えるよう公式が案内しています。駐輪場は熊谷市役所本庁舎の西側駐車場内です。バイク：第1公式有料駐車場に1台1,000円(現金)で駐車できます。

会場のすぐ近くまで車で送迎できる？

おすすめしません。16時以降は会場周辺が広範囲で通行止めになり、河川敷の会場付近は一般車進入禁止です。送迎は規制エリア外（市街地北側など）で乗降し、徒歩または「お帰りロード」動線を使うのが現実的です。
