# 熊谷花火大会 駐車場ガイド 2026 🎆

第74回熊谷花火大会（2026年8月8日(土) 19:00–21:00・荒川河畔）の駐車場情報を、公式発表と地図情報をもとに一覧化したモバイルファーストのガイドサイトです。

**公開URL:** https://yaketa.github.io/suzuki/

## コンテンツ

- ⏰ 当日のタイムライン（開場・規制・出庫時刻を時系列で表示、現在時刻に連動）
- 🅿️ 公式有料駐車場（akippa 完全事前予約制）第1・第2の詳細（入出庫時間・一方通行・入場ルート）
- 🏙 市街地の臨時開放駐車場 5カ所＋市役所（熊谷市公式・交通規制図より）
- 🪙 熊谷駅周辺コインパーキングの参考情報
- 🗺 Leaflet + OpenStreetMap による駐車場マップ（Google マップへのナビリンク付き）
- 🚧 交通規制まとめ（公式規制図 PDF へのリンク付き）
- 💡 満車時のプランB・FAQ

## デプロイ

`docs/` 配下の静的サイトを GitHub Actions（`.github/workflows/deploy-pages.yml`）で GitHub Pages にデプロイします。

> **注意:** GitHub Pages を初めて有効化する場合は、リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定してください。また、無料プランではリポジトリが **Public** である必要があります。
